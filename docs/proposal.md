# 企画書：時間キャパシティ・ブロック管理アプリ「TimeFit」 (Webアプリ版)

## 1. コンセプト
**「タイムライン」から解放され、「ブロック」で1日のキャパシティを塗りつぶす。**
タスクを「何時から何時までやるか」ではなく、「今日確保した時間枠の箱にどれだけ詰め込めるか」を視覚的かつ直感的に管理する、新しいタスクプランニングツールです。

## 2. 画面UIとレイアウトの全体像
PCのWebブラウザ向けに最適化し、画面を「左：タスクプール」と「右：週次キャパシティボード」の2ペインで構成します。

### 【左ペイン】タスクプール（絵の具のパレット）
* **タスク一覧と直感的な時間調整:**
  * 作成したタスクが一覧表示されます。
  * 各タスクには「全体見積もり時間」が表示されており、横の `+` `-` ボタンや数値の直接入力で、いつでも全体時間をサクッと増減できます。
* **親子タスクの階層表示:**
  * 大きなタスクはアコーディオン形式で展開し、中に「子タスク」を作成できます。
  * 子タスクにもそれぞれ見積もり時間を設定でき、子タスクの合計時間が親タスクの時間を超過しないよう連動して管理されます。

### 【右ペイン】週次キャパシティボード（キャンバス）
* **縦積みブロック表示（タイムライン非依存）:**
  * 月曜〜日曜が横の列（カラム）として並びます。時間割ではありません。
  * その日の「確保可能時間」の分だけ、**「1時間＝1ブロック」として空の四角いブロックが縦に積まれています**（例：5時間確保した日は、空ブロックが縦に5つ並ぶ）。
* **デフォルト時間の曜日繰り返し設定:**
  * 「平日は3時間、土日は0時間」といった曜日ごとのデフォルト確保可能時間をあらかじめ設定・反復できます。
  * 特定の日のブロック数を増減させたい場合は、ボード上でその日だけ個別に上書き調整が可能です。

## 3. コア体験：「塗る」ようなタスク割り当て操作
タスクの割り当ては、従来のドラッグ＆ドロップではなく、**「左で選んで、右をなぞる」**という直感的なペイント操作で行います。

1. **タスクの選択:** 左のタスクプールで、割り当てたいタスク（または子タスク）をクリックして「選択状態（アクティブ＝筆に絵の具をつけた状態）」にします。
2. **ブロックを塗る（ドラッグ）:** 右の週次ボードの空きブロックの上で、マウスをドラッグ（クリックしたまま上下になぞる）します。
3. **時間の消化と連動:** なぞったブロック数（＝時間）だけ、そのタスクの固有カラーでブロックが塗りつぶされます。
   * 同時に、左ペインのタスクの「残り時間」と、該当する日の「残り空きブロック」がリアルタイムに差し引かれます。
   * 塗りすぎた場合は、もう一度なぞり直すか、クリック等で簡単にキャンセル・修正できます。

## 4. 2つの割り当てアプローチへの対応
タスクの解像度に合わせて、以下の2つの使い方がシームレスに混在できます。

* **A. ざっくり割り当て（親タスクから直接）**
  * 「資料作成（計5h）」を左で選択し、月曜のブロックを2つ（2h分）、火曜のブロックを3つ（3h分）なぞって塗る。
  * 詳細な手順は未定だが、とりあえず大枠の時間を確保したい時に最適です。
* **B. かっちり割り当て（子タスクから）**
  * 「動画編集（計10h）」を展開し、子タスクの「カット作業（3h）」を選択。水曜日のブロックを3つなぞって塗る。
  * 子タスクの残時間がゼロになれば割り当て完了。親タスクの残り時間も連動して減ります。

## 5. 開発・技術的メリット
* **グリッドとペイントのUI:** 複雑なカレンダーライブラリは不要。シンプルなCSS Gridでブロックを描画し、マウスイベント（`onMouseDown`, `onMouseEnter`, `onMouseUp`）を組み合わせることで、「なぞって塗る」軽快な操作感をWeb上で実現できます。
* **時間単位のシンプル化:** 「1時間（または30分）」を最小単位のブロックと割り切ることで、データ構造もUIも極めてシンプルになり、開発スピードが格段に上がります。
