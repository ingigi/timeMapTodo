# 外部設計書 (External Design) - TimeFit (v2 改訂版)

## 1. システム概要
TimeFitは、時間の「塊（ブロック）」でキャパシティを管理するタスクプランニングツールです。新バージョンでは、より詳細なタスク管理と直感的なドラッグ＆ドロップ操作、そしてステータス管理機能が強化されました。

## 2. 画面構成とUI
デザインは提供されたモックアップ画像に基づき、洗練されたモダンなSaaS風のUIを採用します。

### 2.1 ヘッダー
- 検索バー、通知アイコン、ユーザープロフィール。
- ダッシュボード、設定、レポートへのナビゲーション。

### 2.2 タスクプール (Task Pool - 左サイドバー)
- **タスクカードの表示内容**:
  - タスク名、分類タグ（チップ形式）、期限日。
  - 残り時間 / 合計時間の表示（例: `Remaining: 1.0h / 2.0h`）。
  - 進捗バー（配置済み時間 / 合計時間）。
- **操作**:
  - **直接ドラッグ**: カードをサイドバーからカレンダーエリアへ直接ドラッグして配置。
  - **詳細表示**: カードをクリック（タップ）すると、手書き風の「タスク詳細ポップアップ」が表示。
- **フィルタ・ソート**:
  - 「新規タスク」ボタンの隣にアイコンを配置。
  - **フィルタ**: ステータス（完了・進行中・未着手）、分類タグ。
  - **ソート**: 期限（近い順/遠い順）、残り時間（多い順/少ない順）、タスク名（昇順/降順）、タグ、ステータス。

### 2.3 カレンダーエリア (右メイン)
- **週次/月次ボード**:
  - 配置されたタスクカードには、内部に `+` ボタンが配置され、直接時間を増減可能。
  - 配置されたカード自体のドラッグによる日付移動が可能。

## 3. タスクの属性とステータス

### 3.1 拡張された属性
- **タスク名**: タイトル。
- **分類タグ**: 複数のタグを付与可能。
- **期限日**: タスクの締め切り日。
- **説明**: 詳細なメモ。
- **合計時間**: 必要と見積もった全時間。
- **残り時間**: 合計時間 - 配置済み時間。

### 3.2 自動ステータス判定
- **完了 (Completed)**: 合計時間がすべて配置済みであり、かつ配置されたすべての日付が「今日より前」である。
- **進行中 (InProgress)**: 配置された日付に「今日」または「今日以降」が含まれる。
- **未着手 (Not Started)**: 1時間も配置されていない。

## 4. 特徴的なUI要素
- **手書き風ポップアップ**: 詳細設定画面は、親しみやすさを出すために手書き風の有機的なデザイン（波打つ境界線など）を採用。
